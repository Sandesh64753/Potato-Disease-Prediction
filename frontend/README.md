# Potato Predictor Frontend (Vite + React + Tailwind)

This frontend is a modern Vite + React app designed to integrate with the existing FastAPI backend at `http://localhost:8000` by default.

Quick start:

1. Copy `.env.example` to `.env` and edit `VITE_API_BASE_URL` if your backend runs elsewhere.
2. Install dependencies:

```bash
cd frontend
npm install
```

3. Run dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
